imping

API docs for imping, a Rust toolkit to patch and extend existing programs. Source: WoefulWolf/imping

  • imping_runtimeWhat generated bindings call into: module identity checks, globals and hooks.
  • imping_hookIn-process function hooking: typed detours and code injection.
  • imping_buildGenerates bindings from a build script, and the imping CLI.
  • imping_codegenRust bindings from IR.
  • imping_irThe intermediate representation (IR) types and JSON Schema.
